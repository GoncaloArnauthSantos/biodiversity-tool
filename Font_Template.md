# Branded word document template

## Font colour
Main body text colour: Hex #282E3F
Dark blue: Hex #28286C
Light blue: Hex #5C71D7
Green: Hex 50C27B

## Font type
Primary font type: Lato (Trebuchet if not available) 
Used for: titles and main body text 

Secondary font type: Lora (Times New Roman if not available) 
Used for: chapter headings, subtitles, categories, numbers


## System fonts
Primary system font type: Trebuchet

Secondary system font type: Times New Roman

Sub heading (main body bold): size 11, lato, hex #5C71D7

Main body text: size 11, lato, hex #282E3F
